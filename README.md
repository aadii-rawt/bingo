# Service Booking Platform

A full-stack service booking platform built using the MERN stack.

The platform supports three types of users:

- Customer
- Vendor
- Admin

Customers can browse services, select offerings, choose available slots, create bookings, and make payments.

Vendors can manage services, offerings, availability, bookings, and payments.

Admins can manage vendors, services, categories, and bookings across the platform.
